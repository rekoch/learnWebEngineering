# Willkommen
Dieser Kurs ermöglicht dir einen Einstieg in die Webentwicklung. Anhand einer beispielhaften Blogseite baust du Schritt für Schritt eine Webseite nach und lernst, wie Inhalt, Gestaltung und Interaktion zusammenspielen.

## Wie hängt das zusammen?

Eine Webseite im Browser entsteht aus mehreren Bausteinen:

```text
Webseite im Browser
├── HTML        Inhalt und Struktur
├── CSS         Aussehen und Layout
└── JavaScript  Verhalten und Interaktion
	├── React   UI-Bibliothek für Komponenten
	└── Angular Webframework, meist mit TypeScript
```

- **HTML** beschreibt den Inhalt und seine Struktur, zum Beispiel Überschriften, Bilder und Buttons.
- **CSS** gestaltet diese Elemente: Farben, Abstände, Schrift und das Layout auf verschiedenen Bildschirmgrössen.
- **JavaScript** macht die Seite interaktiv, zum Beispiel indem ein Button auf einen Klick reagiert.
- **React** ist eine JavaScript-Bibliothek für Benutzeroberflächen. **Angular** ist ein umfassendes Webframework, das meist mit TypeScript verwendet wird. Beide helfen dabei, Oberflächen aus wiederverwendbaren Bausteinen, sogenannten Komponenten, aufzubauen und zu aktualisieren.

Ein Like-Button macht das Zusammenspiel greifbar: HTML legt den Button an, CSS gestaltet ihn, und JavaScript zählt die Klicks. Mit React oder Angular lässt sich der Button als eigene Komponente bauen, die ihren Zählerstand selbst verwaltet.

## Wieso lohnt sich das?

Mit diesen Grundlagen kannst du eigene Webseiten bauen und besser verstehen, wie sie funktionieren. Du lernst, Probleme selbst zu finden und zu beheben, statt nur fertige Lösungen zu übernehmen. Das Wissen hilft dir auch später mit Werkzeugen wie React und Angular: Du erkennst, welche Aufgabe sie übernehmen und was im Browser passiert.

Wir beginnen mit HTML und CSS und ergänzen danach JavaScript. So baust du dein Wissen Schritt für Schritt auf.

Viel Spass beim Lernen und Ausprobieren!
