# TypeScript
JavaScript erlaubt viele Freiheiten. Dadurch können jedoch auch leichter Fehler passieren. TypeScript ergänzt JavaScript um eine Prüfung des Codes, die dabei hilft, manche Fehler frühzeitig zu erkennen.

TypeScript wird vom Browser nicht direkt ausgeführt. Deshalb muss der Code vor dem Einsatz im Browser in JavaScript umgewandelt werden. Diesen Vorgang nennt man «Transpilieren».

Diese Umwandlung erfordert eine entsprechende Entwicklungsumgebung und macht den Einstieg etwas komplizierter. Dafür hilft TypeScript, Fehler zu erkennen, bevor du sie auf einer produktiven Webseite bemerkst.

## Einführung
Auf der [TypeScript-Website](https://www.typescriptlang.org) findest du einen guten Einstieg mit Übungen und Erklärungen. Du kannst TypeScript separat lernen oder es laufend anwenden, wenn du zum Beispiel mit React oder Angular weitermachst.

### Empfehlung
TypeScript ohne praktischen Code zu lernen, kann trocken sein. Es lohnt sich trotzdem, sich damit zu befassen, bevor du ein grösseres Projekt startest. Eine kurze Einführung findest du zum Beispiel unter [TypeScript für JavaScript-Erfahrene](https://www.typescriptlang.org/docs/handbook/typescript-in-5-minutes.html).

Danach kannst du mit einem Projekt starten und TypeScript direkt einsetzen. Am Anfang wirst du vielleicht noch mit Fehlern kämpfen. Visual Studio Code und andere IDEs erkennen TypeScript jedoch gut und unterstützen dich dabei. Wenn du nicht weiterkommst, nutze die [TypeScript-Website](https://www.typescriptlang.org) als Referenz.
