# React
React ist eine JavaScript-Bibliothek, die dir das Bauen von Benutzeroberflächen für Webseiten (Webapps) erleichtert. Mehr dazu findest du unter [React](https://react.dev).

## Herausforderungen klassischer Webentwicklung
Vielleicht ist dir in den vorangehenden Themen aufgefallen, dass sich Code manchmal wiederholt. Zum Beispiel haben mehrere Artikel oft denselben HTML-Aufbau, obwohl sich ihre Inhalte unterscheiden:

```html
<article>
  <p>Beispielbeitrag</p>
  <h2>Ein kleines Beet, viele Möglichkeiten</h2>
  <p>von Nora Linden</p>
</article>

<article>
  <p>Beispielbeitrag</p>
  <h2>Ein kleiner Garten mitten in der Stadt</h2>
  <p>von Nora Linden</p>
</article>
```

Die Idee, wiederverwendbare Vorlagen mit Platzhaltern zu schreiben, ist nicht neu. Frühere Template-Systeme erzeugten daraus fertiges HTML, etwa beim Erstellen der Website oder auf dem Server.

Mit React definierst du solche Bausteine als wiederverwendbare Komponenten. Ihre Oberfläche beschreibst du mit JSX, einer HTML-ähnlichen Syntax, die in JavaScript verwendet wird. So kannst du JavaScript-Ausdrücke, zum Beispiel Daten oder Bedingungen, in die Oberfläche einbauen. Entwicklungswerkzeuge wandeln JSX in JavaScript um, das React nutzt, um die Oberfläche darzustellen und bei Änderungen zu aktualisieren.
