# Blogbuttons mit React-State

Der Beispielstand zum Kapitel «Buttons mit React». Die Seite ist vorerst eine einzige grosse `App`-Komponente. Die Like- und Follow-Buttons reagieren auf Klicks. Ihre Zustände bleiben lokal im Browser; nach einem Neuladen stehen sie wieder auf den Startwerten. Es gibt keine Backend-Anbindung.

## Starten

```sh
npm install
npm run dev
```

Für den Produktionsbuild:

```sh
npm run build
```

Die Styles werden vorerst direkt aus dem vorherigen JavaScript-Projekt eingebunden.
